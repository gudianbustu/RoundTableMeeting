# 会议工作台页面设计

页面沿用AuthenticatedLayout、会议导航、头部、005消息区域和参与者侧栏。当前会议由/meetings/:meetingId定位；未选择显示创建/加入入口，加载失败显示重试，不用空状态隐藏错误。

页面消费[客户端模块](../../Modules/MeetingWorkspace/design.md)，不直接发原始请求。活跃与历史共用页面，依据permissions控制输入、邀请、编辑、退出/删除；历史区域仍加载消息与附件。切会时取消旧请求，保留每会话阅读锚点由005处理。

桌面保持导航与主区，窄屏使用导航/参与者抽屉并管理焦点返回。页面标题按[客户端设计](../../design.md)维护。退出通知重载权限并转历史；删除通知移出入口并清理本会议页面数据，不保留只读归档。
