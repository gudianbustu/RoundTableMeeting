# 加入会议对话框设计

## 1. 职责与行为

输入会议码后预览会议名/背景，确认或修改首次显示名再提交。已加入显示已有身份，已退出明确提示重新加入将恢复完整历史；普通查看历史不走此流程。

## 2. 输入与协作

preview/join回调、loading与字段错误；预检不是授权承诺，最终Join再次校验。已存在身份不因输入另一名称改变。

## 3. 边界

格式/名字冲突/删除会议/限流分别反馈，失败保留输入；会议码不写URL或持久浏览器存储，取消清理敏感状态。

状态与权限以[客户端设计](../../design.md)及[服务端契约](../../../Server/design.md)为准；组件不建立第二套生命周期规则。
