# 添加账号表单设计

## 1. 组件职责

`CreateUserForm` 收集用户名、昵称和初始密码，执行客户端长度与必填校验并向页面提交。它不决定用户名唯一性，也不把密码写入长期状态或持久化存储。

## 2. 字段

- 用户名：必填，原始输入最多 128；服务端最终规范化显示值最多 64。
- 昵称：必填，最多 64。
- 初始密码：密码控件，至少包含一个非空白字符且最长 256；不 Trim，合法密码的首尾空格按原值提交。

不提供角色、状态、确认密码或首次登录改密选项。

## 3. 错误与提交

- 本地空字段错误绑定到字段。
- 服务端 `validation_failed` 映射字段错误。
- `username_conflict` 固定绑定用户名字段。
- 网络错误显示安全表单级提示。
- 提交中禁用重复提交。
- 失败后保留用户名和昵称，清空初始密码。
- 成功后由页面关闭弹窗并销毁表单值。

## 4. 安全边界

密码不写入 URL、localStorage、sessionStorage、日志或错误详情。浏览器自动填充使用 `new-password` 语义。

创建结果固定为普通用户；表单不接受 isAdmin。管理员身份需要在创建成功后通过列表的独立操作授予。
