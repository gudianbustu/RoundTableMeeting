# 会议工作台实现计划

## 1. 阶段与前提

以[设计](design.md)及[测试计划](testPlan.md)为准。用户已授权当前会话实施总体计划第1批，先完成第0批必要准备。当前执行范围为参与权限与会议生命周期；私聊收发、附件产品能力和完整网页交互归后续批次，不以本批通过代替主题全部验收。复用现有分层和工程，手写扩展；允许在测试实例及隔离数据库副本验证增量迁移，不操作共享运行库、不重启既有服务、不发布或主动提交。

## 3. 交接要求

先核对目标工程的实际类型、公开依赖和旧数据，再按本主题唯一契约修改；新增字段/接口须同步真实OpenAPI、适配和必要测试。任务细节归相应端/模块计划，根文档组织顺序，不维护重复完成状态。迁移必须使用隔离副本验证，不能直接操作共享运行库。

完成需提供测试计划中的真实证据；未执行项目保持待验证，文档检查不计作运行通过。提交、部署和重启仍按后续授权执行。

## 4. 本批实施范围

第1批覆盖I01/I02及I05的服务端生命周期与权限部分，具体实现及验证状态维护于[服务端计划](Server/impl.md)。I03已按隔离宿主真实OpenAPI重新生成客户端，并补齐删除中/已删除的410错误及实时通知处理；I04完整Web退出/历史交互及私聊入口随后续批次处理。本批服务端已实现，验证和未交付部分见服务端计划。元数据编辑与会议Revision、参与者私聊可见投影不计入本批完成范围。
