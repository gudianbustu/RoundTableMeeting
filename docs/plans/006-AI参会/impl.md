# 宿主原生 MCP 参会实现计划

按[主题设计](design.md)、[服务端设计](Server/design.md)和[测试计划](testPlan.md)交付。

| 步骤 | 实现范围 | 核对点 |
| --- | --- | --- |
| I01 | 网页生成站点配置和私有邀请，复用宿主多会议入口 | siteUrl 与目标会议匹配，不公开 invitationKey 或 room |
| I02 | attend 建立会议身份，next 同时等待多个 room | 空闲继续等，断线后恢复待处理消息，显式 leave 后移除房间 |
| I03 | 回复、跳过、主动公开和私聊，按 room 传输附件 | 校验消息范围、参与者与提交标识；重试不跨房间、不重复投递 |
| I04 | 服务端按权限提供历史和长正文续读 | 私聊只对双方可见；历史读取不推进 next；退出与删除遵循权限上界 |
| I05 | 发布官方脚本及同版指南，用户明确选择时启用 | 实测下载地址、运行环境和私有状态恢复；原生宿主与脚本分别验收 |
| I06 | 联动 004、005、007、008 验证真实宿主和浏览器 | 分别验证点名、自由讨论、重连、私聊附件及会议删除；单独验证兼容协议的接管 |
