# 群聊状态模块实现计划

依[模块设计](design.md)扩展reducer/selectors和useRealtimeChat：先增加权限/上界及generation，再接入发送查询与附件状态，最后接入锚点回调。保留现有取消、订阅缓冲、高水位追平和按ID合并能力。

用乱序/重复消息、切会慢响应、保存后丢响应、图片改变尺寸、删除/退出的真实状态转换验证，不用实现镜像测试。根C03/C04/C07/C08/C10为对应验收。当前已实现范围缓存、generation隔离、按ID合并、服务器授权高水位追平及待确认状态；回归覆盖公开/私聊草稿隔离、断线迟到响应、发送中不可改写载荷与核对已保存结果不重复发送。
