# 多 Agent 自由交流、私聊与删除退出集成设计

## 1. 主题定位

依据 FR-011、FR-015、FR-017，复用[004生命周期](../004-会议工作台/Server/design.md)、[005公开/私聊与附件](../005-实时群聊/Server/design.md)、[006官方CLI](../006-AI参会/design.md)、[007可靠连接](../007-AI任务连续性与接管/design.md)。保留目录，不新增主题或平行删除服务；本主题组织跨主题验收，契约及实现回到所属主题。

## 2. 自由交流和私聊

人类、Agent自主发送公开或同会议一对一私聊；系统消息按005公开规则处理。@只表达关注，不生成回复任务或裁决责任。CLI后台接收全部有权消息，前台read与wait位置独立，私聊无需@即匹配接收者wait，不要求模型回复或保证宿主唤醒。

私聊正文、附件及发生情况仅双方身份可见，创建者和管理员无额外权。联调必须检查HTTP、实时事件、历史、附件、检索、计数、序号和日志；隐藏界面不能代替权限。接管原Agent身份继承其有权私聊，原连接代次失效。网页和CLI回复保留原范围，显式公开发送建立新意图，不自动带出原私聊引用或附件。

## 3. 退出与删除

会议存续时，非创建者退出只停止本人参与，保留退出前有权公开历史与已有本人私聊/附件；任一方退出暂停该双方私聊新发送，其他成员仍正常交流。离线不等于退出，可继续留言。明确重入开放会议才恢复参与与有权公开历史，双方均joined才恢复私聊；普通重连、接管或历史查询不替代重入。

创建者不能退出，可离线或删除会议。删除沿用输入会议名称确认并提示删除范围，不增加确认步骤。004提交屏障后阻止所有内容访问、移除入口；清理公开/私聊、文件及派生记录完成才报告deleted。删除不是历史归档，原私聊双方与已退出者也无权查看。其他会议不受影响。

CLI收到可信删除完成状态后，按006清除本会议全部会话受管原文、索引、缓存及正文派生数据，取消任务阻断回写；离线恢复先确认生命周期再同步。用户另存文件、已输出内容及Agent上下文不保证收回，不以能收回外部副本为验收条件。

## 4. 组合时序与故障

发送与删除/退出共用004短事务：发送先提交则退出边界包含它，但随整会删除清除；屏障或退出先提交则拒绝新发送。私聊双方状态都在提交时校验。发送响应丢失后，退出可核对已有结果；删除不能返回旧内容或重发。未绑定上传与已绑定附件均随整会删除清理，晚到上传、通知、索引结果不得复活数据。

Web通知丢失以后续授权收敛；CLI删除证明独立于历史凭据，断开、退出或被接管的旧会话也可只查删除状态，不借此读取私聊。普通网络故障/404不触发不可逆本地清理。文件占用、服务重启及数据库失败保持deleting并恢复同一清理操作，不能将处理中标成完成。

## 5. 交接

保留存续会议真实消息、作者、顺序与附件；迁移既有消息为public，建立本人可见投影，旧Deleting按004已提交意图恢复。停用旧任务来源链及回复任务消费者，不能停用本轮要求的整会删除恢复。用隔离旧库验证，不直接操作共享运行数据。

[实现计划](impl.md)组织依赖，[测试计划](testPlan.md)覆盖公开/私聊、接管、退出、删除和恢复组合。只有真实浏览器、两个独立CLI及故障验证完成，才能声称业务验收通过；本轮只同步文档。
