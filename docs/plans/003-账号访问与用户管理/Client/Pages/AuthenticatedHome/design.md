# 登录后首页设计

## 1. 页面定位

`AuthenticatedHomePage` 是主题二的最小登录后占位页面，用于证明当前用户身份已经建立并且受保护路由可用。它不是会议工作台，也不在页面主体重复承载会议、消息或用户管理功能；用户管理入口由认证后布局统一提供。

## 2. 进入条件

- 路由为 `/`；
- `AuthGate` 状态为 `authenticated`；
- `useAuthentication()` 已经取得服务端确认的当前用户资料。

未认证、认证检查中或认证初始化失败时，页面不自行渲染成功内容，由 `AuthGate` 处理对应状态。

## 3. 页面结构

页面只包含：

1. `AuthenticatedLayout` 提供的应用壳。
2. 简短的身份确认内容，显示 `UserId`、用户名和昵称。
3. 后续会议主题接入位置。

页面不显示模拟会议、模拟消息、用户管理入口或虚假的业务数据。

## 4. 交互流程

1. 页面从认证 Context 读取当前用户。
2. 显示当前账号的 `UserId`、用户名和昵称。
3. 用户通过 `AuthenticatedLayout` 中的 `CurrentUserBar` 点击退出并调用认证模块。
4. 认证状态转为匿名并导航到 `/login`。
5. 用户返回页面或直接请求 `/` 时，服务端认证边界再次决定是否允许访问。

## 5. 页面边界

页面不请求账号详情以外的业务数据，不保存当前用户资料副本，不实现会议列表、会议创建、聊天消息、AI 协作或账号设置。主题三可以替换页面主体，但必须继续使用主题二的认证布局和当前用户上下文。
