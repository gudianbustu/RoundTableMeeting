# 会议导航组件设计

## 1. 组件职责

`MeetingNavigation` 展示当前账号可访问的会议列表，触发创建和加入入口，并通过路由切换当前会议。组件不查询服务端、不解析会议码、不判断会议权限。

## 2. 展示内容

每个列表项展示会议名称、当前用户首次加入时间和该会议中的显示名称；创建者使用文字标记区分。首版不展示未读数量、最后消息、参与者数量、在线状态或会议码。

列表按服务端返回顺序渲染，当前 meetingId 使用选中态。空列表显示创建和加入两个入口；加载和错误状态使用统一的列表状态组件。

## 3. 交互

- 点击列表项导航到 `/meetings/:meetingId`。
- 点击创建按钮打开 `CreateMeetingDialog`。
- 点击加入按钮打开 `JoinMeetingDialog`。
- 会议被删除或返回不可访问时由父模块移除列表项，组件不自行猜测。

桌面端使用固定宽度侧栏；移动端使用可展开的选择器或抽屉。按钮使用熟悉图标并提供 tooltip，文字按钮仅用于创建和加入等清晰命令。

## 4. 可访问性与边界

列表项使用可聚焦的按钮或链接语义，当前项提供 `aria-current`。长名称允许换行；列表不因名称长度改变侧栏宽度。
