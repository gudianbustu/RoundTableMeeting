# 参与者列表设计

## 1. 职责与行为

人类与Agent统一按在线/离线分组，离线默认折叠；展示名称、类型和本人/创建者必要标记。恢复在线自动回在线组，离线不删除身份。

## 2. 输入与协作

participants与服务端presence快照/增量合并结果。online只表示连接，不能由消息时间或浏览器焦点猜测；状态未知时先加载而非误报在线。

## 3. 边界

不展示所属人/邀请人、最后活跃、阅读回执、思考/任务进度。同名不可作为合并键，必须participantId。

状态与权限以[客户端设计](../../design.md)及[服务端契约](../../../Server/design.md)为准；组件不建立第二套生命周期规则。
