# 多方交流与关闭退出集成测试计划

## 1. 依据与证据

需求见[增量需求](../../需求分析/圆桌会议推广使用增量需求.md)，契约见[设计](design.md)。以下全部是待执行验收，不预填通过。单元测试验证确定性规则，真实SQLite验证约束/事务，进程测试验证崩溃恢复，浏览器和官方CLI验证可观察流程；真实模型证据单独记录。

## 2. 场景矩阵

| 编号 | 需求/验收来源 | 输入与操作 | 预期 |
| --- | --- | --- | --- |
| E01 | FR-011/AC-011 | 人类、AgentA、AgentB自主发言，单目标/多目标/自提及/引用 | 共同消息流，@只筛选，不创建强制任务或平台业务责任 |
| E02 | FR-003/009与AC | A长期处理不回复，B和人类继续发普通及系统消息 | 后台完整接收，读取/检索仍可用，无失败队首 |
| E03 | FR-015/AC-015 | 一成员退出后其他人发消息并关闭会议 | 退出者只见退出前；其他原成员见关闭前；附件同范围 |
| E04 | FR-015/AC-015 | 退出者仅浏览/重连/接管，再明确用码加入开放会议 | 前三者不恢复参与；明确加入恢复全历史；关闭后全部拒绝再加入 |
| E05 | FR-001/015与AC | 上传后未发即关闭、已绑定后关闭、边界时下载 | 未绑定不形成成功消息；已绑定长期保存，权限外不下载 |
| E06 | FR-009/013/015与AC | 消息保存响应丢失再退出或关闭；旧连接迟到重试 | 可核对原发送，不产生新消息或恢复活跃连接 |
| E07 | 多会议隔离 | A关闭/故障，B持续聊天及检索 | B不阻塞且无数据、凭据或状态串线 |
| E08 | 真实与脚本证据 | 两个真实外部Agent回答不同问题；脚本注入重复、乱序和崩溃 | 分别证明自由交流和传输可靠性；模型质量不作平台保证 |

## 3. 数据与执行边界

使用隔离数据库和两个会议、创建者/普通成员/退出成员/非成员，以及两个独立Agent会话；包含空历史、足够跨页历史和Unicode正文。权限与并发用真实事务和可控时钟验证，不能只模拟成功DTO。附件用隔离目录，网络中断与进程重启仅对测试实例执行。

浏览器检查DOM、网络、控制台及必要截图，CLI保存脱敏命令/退出码与服务端关联标识。不得把账号、邀请码、令牌或完整私人正文写入测试报告。支持矩阵、模型资源和持续运行结论必须标明实际环境及样本边界。

## 4. 完成判定

所有受影响场景与前置主题回归通过，且关键异常与权限边界有真实证据，才可判定实现可验收。仅文档链接、构建或固定回复通过不能代替本矩阵。当前未执行业务测试。
