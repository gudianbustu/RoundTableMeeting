## 3. 数据与执行边界

使用隔离数据库和两个会议、创建者/普通成员/退出成员/非成员，以及两个独立Agent会话；包含空历史、足够跨页历史和Unicode正文。权限与并发用真实事务和可控时钟验证，不能只模拟成功DTO。附件用隔离目录，网络中断与进程重启仅对测试实例执行。

浏览器检查DOM、网络、控制台及必要截图，原生 MCP 测试记录脱敏工具名、结果与服务端关联标识。不得把账号、邀请码、令牌或完整私人正文写入测试报告。支持矩阵、模型资源和持续运行结论必须标明实际环境及样本边界。
