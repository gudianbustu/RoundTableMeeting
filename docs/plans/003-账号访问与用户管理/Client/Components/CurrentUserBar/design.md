# 当前用户栏组件设计

## 1. 组件职责

`CurrentUserBar` 在登录后应用壳中显示服务端确认的当前用户资料，并提供个人设置导航和退出操作。它不解析 Cookie、不读取客户端持久化身份、不判断会议权限。

## 2. 输入与行为

组件从 `useAuthentication()` 读取：

- 当前用户昵称；
- 当前用户名；
- 认证状态；
- `logout()` 操作。

用户点击退出按钮后调用 `logout()`，不直接调用 HTTP API。

## 3. 显示规则

- `authenticated` 状态显示昵称，并可辅助显示用户名。
- `checking`、`anonymous` 和 `error` 状态不显示过期的旧用户资料。
- 服务端契约保证昵称规范化后非空；组件仍保留通用占位文本作为防御性回退，但正常业务和验收不得依赖该分支。
- 退出请求进行中禁止重复点击，并提供明确的进行中状态。
- 退出请求发生 403、网络或未知错误时显示可重试错误，并继续显示当前用户；只有服务端以 204 确认退出后才清理身份。

## 4. 组件边界

退出后的导航由认证模块或应用布局统一处理，组件只触发操作并呈现状态。组件提供到 `/settings/profile` 的个人设置入口，编辑表单在独立页面；不在顶栏承载账号管理或会议操作。

## 5. 样式边界

优先使用 Ant Design Space、Typography、Button 和 Tooltip 等基础组件。退出是明确命令，可以使用图标加文字；图标按钮需要提供可访问名称或 Tooltip。
