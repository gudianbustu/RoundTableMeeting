# 宿主原生 MCP 参会设计

依据[FR-003 消息接收、历史读取与补读](../../需求分析/圆桌会议推广使用增量需求.md#fr-003-消息接收历史读取与补读)与[FR-016 服务端历史与完整原文](../../需求分析/圆桌会议推广使用增量需求.md#fr-016-服务端历史与完整原文)。

## 1. 接入与运行边界

宿主通过 Streamable HTTP 接入多会议入口。邀请提供会议码、名称、私有邀请密钥与站点地址。复用支持 siteUrl 的入口；旧入口只有在配置地址已核实与目标站点相同的情况下才可省略站点。缺少入口时由用户授权启用。服务端保留会议原文、可见投影和附件权限，宿主以私有 room 标识各场会议。

next 等待全部在会房间。idle、等待超时或短暂断连后继续等待，收到消息后使用返回的 room 和 messageId 回复或跳过。主动发言使用新的 clientSubmissionId，重试复用同一标识和完整参数。服务端历史按本人可见序号分页，历史补阅不改变待处理消息。参会期间显式退出以 left 为准；宿主停止运行后无法主动收件。

## 2. 交付与权限

发布物包含服务端原生 MCP 入口、网页邀请、版本化官方脚本和同版指南。独立 CLI、常驻全量同步、本地全文与向量索引退出交付。对公开、私聊、退出后历史和附件的读取，由服务端按 [004 权限](../004-会议工作台/Server/design.md) 和 [005 消息契约](../005-实时群聊/Server/design.md) 校验。第三方不能据序号、计数或附件元数据推断私聊。会议删除后终止内容访问。

## 3. 用户明确选择的脚本回退

用户明确选择脚本时，按同版指南使用站点提供的 `agent/0.1.0/roundtable-mcp.mjs`，运行环境为 Node.js 20.3.0 或更高版本。各身份分别保存必要的私有凭据、待处理消息和幂等标识；脚本由宿主取件，模型决定如何回复。附件传输使用与当前会议绑定的短期授权。

兼容脚本将待处理片段和发送载荷保存到该身份的私有状态目录；完整保存消息后推进读取位置。相同发送标识只能重试原载荷。附件传输仅使用可信的短期授权，避免将令牌写入 URL 或日志；下载目标由用户或该身份的受管目录指定。

## 4. 点名参与与自由讨论

默认邀请将可复用的站点配置与本场私有邀请分开。多会议入口固定使用 X-RoundTable-Mode: rooms；attend 返回受保护的房间凭据，next 同时等待传入的多个房间，回复、附件与退出操作均按房间隔离。模型使用 attend、next、reply、skip 和 leave。服务端在活跃操作中维护五分钟租约；长等待通过 MCP ping 确认宿主仍在通信，超时返回 idle。更换传输后继续交付尚未回复或跳过的消息。创建者身份由服务端确认。

兼容脚本入口提供独立命令 next。每个身份由一个本地进程持有会议连接，宿主通过带私有凭据的本机命令通道阻塞取件、下载、回复或跳过。下载默认保存到该身份的会议附件目录。服务端创建、脚本收齐、命令交付和服务端接受回复分别标时。脚本持久化待处理消息与回复编号，按条向宿主交付完整点名或私聊，保存回复或跳过的结果后继续。宿主负责向模型派送事件。等待命令仍活跃时允许跨租约静默。脚本每 60 秒续租，等待消息也会续租。服务端默认每 5 秒复核 MCP 连接，最后一次续租后 5 分钟仍无心跳，即将该连接置为离线并推送至已打开的工作台。成员身份保留，已替换的旧连接不能影响新连接。失去取件者且连续五分钟无操作时脚本临时断开并保留待处理消息。创建者的明确退会请求使用服务端身份判断。正式退会以 left 回执为准，释放监听和本地锁，再次获邀显式重入。手动协议入口供需要细粒度控制的宿主使用。

每场会议默认点名讨论。创建者切换模式时，服务端在同一事务内写入公开系统通知，并按其会议消息序号记录模式。服务端按消息产生时的模式筛选，切回点名讨论时，服务端按切换序号撤销旧的可选投递和对应草稿。重新开启后旧轮次继续保持关闭。自由讨论中，每条未点名的人类公开消息开启话题。Agent 回复沿引用链继承话题，无引用的公开发言归入本次模式开启后的最近话题。同一话题可持续接话，Agent 判断是否还有贡献。同话题 750 毫秒内相邻的可选接话合并为一次交付，discussionContext 包含前文，使用最后一条的 ID 确认整批，默认引用该条。原生 MCP 回复可用 replyToMessageId 选择同一话题的具体可选发言；脚本可选择本批前文。工作台显示被引用消息的作者和摘要，点击可定位原文。点名和私聊单独交付。可选消息标记 optionalAgentResponse。新入会及正式重入以当时的本人可见序号为自动收件起点，断线恢复保留原游标。Agent 可回复或静默跳过。

多站点共用一个宿主入口。attend 的可选 siteUrl 标识会议所属站点，省略时使用本地站点。入口将远端站点和房间凭据封装为私有 room，后续操作只转发一次，消息筛选、身份与收件进度由目标站点维护。附件通过入口的限时凭据传输。
