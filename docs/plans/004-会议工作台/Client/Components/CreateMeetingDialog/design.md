# 创建会议对话框设计

## 1. 组件职责

`CreateMeetingDialog` 收集会议名称和可选讨论主题/背景说明，提交创建请求并呈现结果。它不生成会议码、不读取当前用户、不直接导航。

对话框每次打开时生成非空 `creationRequestId`，同一次打开期间的所有提交和网络重试复用该值。服务端返回 `creation_request_mismatch` 或 `creation_request_consumed` 时不得自动生成新 ID 或再次提交；先关闭提交态、刷新会议列表并提示用户检查之前的创建结果。只有用户确认要创建另一场会议、关闭后重新打开对话框时才生成新 ID；成功或取消关闭后丢弃。

## 2. 表单

- `name`：必填，Trim + NFC 后 1 至 128 个字符；
- `description`：可选，Trim + NFC 后最多 2000 个字符；空值按未填写提交。

不提供人数上限、密码、有效期、审批、主持人、预约时间或会议结束设置。

## 3. 交互状态

打开时清空上一次未提交内容。提交按钮在请求期间 loading 且禁止重复提交；字段错误就地显示并保留输入；未知或网络错误显示通用提示。取消关闭时清理表单和错误。

创建成功由父模块关闭对话框、刷新列表并导航新会议；组件只通过 `onCreated(result)` 通知成功。

## 4. 可访问性

对话框打开时焦点进入会议名称，Escape 取消，提交支持 Enter。标签和错误与字段关联，窄屏下表单不横向溢出。
