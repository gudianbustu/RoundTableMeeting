# 消息时间线设计

按服务端顺序展示人类、Agent 和系统消息。公开和私聊正文支持 Markdown 标题、列表、引用、代码、链接和表格，普通段落保留换行。发送中与历史消息共用正文渲染，提及按原文位置高亮。原始 HTML 作为文本展示，Markdown 图片显示替代文本，上传图片使用附件预览。每项以messageId为稳定键和锚点。附件清单跳转按ID加载附近页后定位。

时间线测量首个可见消息与像素偏移，通知上层保存锚点；图片/字体/旧页插入后修正。只在底部跟随，按钮主动回最新，无未读数量。

详细状态、48px底部阈值、锚点和安全边界统一见[客户端设计](../../design.md)，不重复定义协议。

时间线接收已授权且选定范围的消息，私聊明确标注双方及发送者；回复回调携带原范围和对象。锚点按会议+范围隔离，公开区域不嵌入私聊预览，不显示私聊活动提示或未读计数。

服务端消息之外展示当前本地待发送项，正文及附件名称保留原载荷。转圈、待确认和失败感叹号依附该项；失败原因与重试通过感叹号展开。成功后替换为已保存消息，不显示成功提示。占位不进入服务端排序及历史水位。

本人消息通过当前参与者ID与作者participantId匹配判断，元信息、正文气泡、图片和附件整体靠右；其他人及系统消息靠左。本人多附件按原顺序单列靠右，每个图片和文件卡片共用右边界，不保留多列网格的空列。正文内部仍左对齐并保留换行，长文本限制宽度。当前本地待发送项同样靠右，状态图标位于内容左侧，成功后方向保持一致；公开及私聊使用相同规则，窄窗口不横向溢出。
