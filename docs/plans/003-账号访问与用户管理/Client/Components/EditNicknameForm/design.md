# 昵称编辑表单设计

## 1. 组件职责

`EditNicknameForm` 修改一个已存在账号的昵称。目标用户名只读显示，用于确认操作对象；组件不提供用户名修改。

## 2. 输入

- 目标 `userId`。
- 只读 username。
- 当前 nickname。
- 提交状态与错误。

## 3. 行为

昵称必填，最多 64；提交时保留用户输入原文，由服务端执行 Trim + NFC。新昵称与当前值相同仍可提交，服务端按幂等更新处理。

`validation_failed` 绑定昵称字段；`user_not_found` 由页面关闭弹窗并刷新列表；网络错误保留输入。

## 4. 业务提示

表单只提示“昵称修改不会改变用户名”。会议内显示名称的同步规则由后续会议主题定义，本组件不提前作出承诺。
