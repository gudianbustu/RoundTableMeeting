# 实时群聊页面区域设计

## 1. 页面定位

`RealtimeChatRegion` 是会议工作台主区域内的真实消息区域，不是独立路由，也不拥有会议删除或会议选择。它在会议工作台主题的消息区插槽位置渲染。

## 2. 区域结构

1. 连接状态条：显示连接中、已连接、重连中、已断开和会议不可访问。
2. 历史时间线：按 sequence 升序展示消息；顶部提供加载更早消息，底部根据用户是否在底部决定自动跟随。
3. 增量加载提示：补齐期间显示轻量状态，不覆盖已有消息。
4. 编辑器：正文输入、提及候选、发送和失败重试。

## 3. 加载状态

- 首次加载无消息时显示骨架或空状态；不显示假消息。
- 有历史时增量加载只在时间线顶部或连接状态条显示，不让整个会议头部跳动。
- 历史失败保留已加载消息，显示重试和连接状态；不清空已确认的服务端消息。
- 会议删除事件或 404 清空消息并触发工作台回退；不自动选择其他会议。

## 4. 滚动和可访问性

用户已在底部附近时，新消息到达后滚动到最新；用户正在查看旧消息时显示“有新消息”提示，点击后再滚动。时间线使用 `role="log"`、可读作者类型和时间文本，屏幕阅读器可区分人类、AI 预留和系统消息。

## 5. 非目标

页面区域不显示未读数、已读位置、消息编辑删除、回复线程、附件或 AI 处理进度。
