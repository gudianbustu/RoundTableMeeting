# 用户列表组件设计

## 1. 组件职责

`UserListTable` 展示账号最小资料并提供单用户操作入口。它不请求 API、不弹出业务对话框、不判断权限。

## 2. 输入与事件

输入包含用户数组、加载状态和正在操作的目标标识；事件包含：

- `onEditNickname(user)`；
- `onResetPassword(user)`。

## 3. 列定义

- 用户名：主识别字段，完整显示并支持长文本换行。
- 昵称：账号默认昵称。
- 操作：编辑昵称图标按钮和重置密码菜单项。

`userId` 作为稳定行键，不默认展示。表格不包含角色、状态、创建时间或密码字段。

## 4. 交互状态

- 列表加载时使用表格 loading，不改变列宽。
- 单个用户操作中禁用该行的昵称修改和密码重置命令，其他用户行保持可用。
- 空数组显示稳定空状态。
- 窄屏操作收纳进更多菜单。

## 5. 组件非目标

搜索、分页、批量选择、删除、权限判断和直接调用 API。
