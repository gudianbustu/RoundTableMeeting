# 创建会议对话框设计

## 1. 职责与行为

保留必填会议名称、可选讨论主题/背景，创建者显示名由账号昵称产生；不加入预约、人数或有效期字段。

## 2. 输入与协作

open、loading、onSubmit/onCancel；一次创建意图生成creationRequestId，网络重试复用。修改内容形成新意图时更新标识，不能同ID不同内容重试。

## 3. 边界

输入规则沿用004服务端设计，前端只改善体验，服务端最终校验。失败保留输入，成功由模块导航新会议。

状态与权限以[客户端设计](../../design.md)及[服务端契约](../../../Server/design.md)为准；组件不建立第二套生命周期规则。
