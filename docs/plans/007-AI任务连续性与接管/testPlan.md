需求见[增量需求](../../需求分析/圆桌会议推广使用增量需求.md)，契约见[设计](design.md)。以下全部是待执行验收，不预填通过。单元测试验证确定性规则，真实SQLite验证约束/事务，进程测试验证崩溃恢复，浏览器和原生 MCP 宿主验证可观察流程；真实模型证据单独记录。

## 2. 场景矩阵

| 编号 | 需求/验收来源 | 输入与操作 | 预期 |
| --- | --- | --- | --- |
| R01 | FR-009 | 复用邀请并恢复会议 | 参与者身份稳定，未处理消息仍可处理 |
| R02 | FR-009 | 宿主持有 next 等待；终止宿主并等待租约过期 | 等待中维持通信；过期显示离线，成员关系保留 |
| R03 | FR-009 | 未经明确授权尝试替换已有身份 | 普通入会不隐式接管 |

| R05 | FR-013 | next 后断开、处理完成前重连，另行读取服务端历史 | 待处理消息可继续；补阅范围正确、不会推进 next |
| R06 | FR-009/013与AC | 保存后丢响应、核对失败、确定未保存、同正文两次发言 | 未知保持待确认；原ID重发仅一条；两个ID保留两条 |

| R08 | FR-015/017与AC | 发送、恢复或兼容协议接管与删除或双方退出并发 | 删除无内容返回；退出仅有权历史、私聊暂停；接管不代替重入 |
| R09 | FR-009 | 查询授权参与者连接状态、跨会尝试取件 | 在线状态仅表明通信有效；其他会议及其内容不可见 |
| R10 | 升级回归 | 旧任务/Deleting存留、服务重启 | 无回复任务复活，已提交删除恢复清理，存续消息迁移投影不丢失 |

| R11 | FR-017/AC-017 | 使用兼容协议显式接管后查私聊与附件 | 新代次继承原身份有权内容；旧代次不能继续读取，其他身份私聊仍不可见 |
| R12 | FR-015/AC-015 | 删除通知丢失、旧连接proof确认、未知proof | 有效proof仅能查生命周期，不能读内容；未知结果不误报deleted |

## 3. 数据与执行边界

使用隔离数据库和两个会议、创建者/普通成员/退出成员/非成员，以及两个独立Agent会话；包含空历史、足够跨页历史和Unicode正文。权限与并发用真实事务和可控时钟验证，不能只模拟成功DTO。附件用隔离目录，网络中断与进程重启仅对测试实例执行。

浏览器检查DOM、网络、控制台及必要截图，原生 MCP 测试记录脱敏工具名、结果与服务端关联标识。不得把账号、邀请码、令牌或完整私人正文写入测试报告。支持矩阵、模型资源和持续运行结论必须标明实际环境及样本边界。

## 4. 完成判定

所有受影响场景与前置主题回归通过，且关键异常与权限边界有真实证据，才可判定实现可验收。仅文档链接、构建或固定回复通过不能代替本矩阵。当前未执行业务测试。
