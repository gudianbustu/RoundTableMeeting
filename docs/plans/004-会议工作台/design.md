# 会议工作台主题设计

## 1. 依据与目标

承接[基础需求](../../需求分析/圆桌会议网站需求.md)及增量FR-005、FR-007、FR-012、FR-015，在现有工作台完成创建/加入、多会议切换、信息编辑、参与者列表、邀请、退出后有权历史与整会删除。沿用002框架与003账号；本轮只修订设计。

## 2. 范围与产品语义

会议创建即开放并长期保存。创建者可编辑名称、讨论主题或背景；已加入人类成员可取得邀请信息。只允许创建者移除会议，移除表示删除会议、公开消息、私聊及全部附件，所有人不可再查看；非创建者可主动退出，保留退出前历史。创建者退出请求必须拒绝，不能隐式删除。

断开连接不改变参与关系。历史入口不重新加入；明确用有效会议码重新加入开放会议才恢复完整历史，沿用原参与身份和显示名。删除后不可重新加入。参与者展示在线/离线，离线组默认折叠，不展示邀请人、所属人、最后活跃、已读或模型工作状态。

不建设预约、主持、踢出、禁言、转让创建者、单条消息删除或回收站。消息/附件实现归005，Agent连接归006/007；本主题提供统一权限与界面组合。

## 3. 契约与单一来源

[服务端设计](Server/design.md)唯一维护模型、规范化、状态、历史上界、API、错误及事务。所有调用方区分历史读取与活跃收发，active+left允许有权历史，deleting/deleted拒绝全部内容访问。共享模型引用[领域图](../../uml/圆桌会议协作模型.puml)。

[客户端设计](Client/design.md)负责工作台状态、当前会议、历史入口和标题同步；组件不自行决定权限。会议代码/元数据/权限变化通过revision收敛，旧请求不覆盖新会议。

## 4. 可见流程

创建后进入会议；首次加入预览名称与背景、确认本人显示名；重复加入复用身份。创建者编辑后刷新详情和导航，当前页面标题同步。移除时提示删除全部公开消息、私聊及附件，沿用输入会议名确认，不增加额外确认；提交后移出会议入口，清理完成才报告删除完成；退出提示“停止参与，仍可查看退出前记录”，只影响自己。

活跃与历史分组共享导航；主动退出后移至历史入口，仍显示有权公开及本人私聊记录/附件，双方私聊停止新发送；删除会议从全部入口移除，清除页面缓存。工作台提供私聊对象选择，具体交流范围与消息UI归005；不显示私聊活动、数量或时间。
