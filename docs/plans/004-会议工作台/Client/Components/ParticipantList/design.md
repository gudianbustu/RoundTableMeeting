# 参与者列表组件设计

## 1. 组件职责

`ParticipantList` 展示当前会议的全部静态参与者，区分人类和为后续主题预留的 AI 类型。组件不订阅实时状态，不显示在线、处理中或离线状态。

## 2. 展示内容

每项显示会议内显示名称、类型文字、人类创建者标记、当前用户标记和加入时间。当前主题不会伪造 AI 条目；当后续主题提供 `agent` 时，组件通过类型联合渲染对应标记。

列表严格按服务端返回的 JoinedAt 升序、ParticipantId 升序渲染，客户端不重新排序。名称允许换行，人数变化不能导致布局抖动。

## 3. 非目标

不提供点击私聊、踢出、禁言、退出、修改名称、状态切换或消息提及操作。后续消息主题可在不改变参与者身份字段的前提下增加选择行为。
