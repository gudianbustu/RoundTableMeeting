# 消息编辑器设计

提供原文输入、参与者@辅助、附件上传和发送；纯附件可发，空正文且无附件拒绝。未知@或无@正常发送，不增提醒。仅权限允许活跃收发时可操作。

展示上传中/失败/就绪及实际限制，发送中/待确认/拒绝准确区分；保留原载荷和草稿，重试由模块协调。不能用模型回复或接收ACK判断发送完成。

详细状态、48px底部阈值、锚点和安全边界统一见[客户端设计](../../design.md)，不重复定义协议。

编辑器接收显式scope和peerParticipantId，持续显示公开或私聊对象。回复继承原私聊范围；切页与@不改目标。公开发送必须显式选择，具体载荷转换按Client设计第7节；不能自动公开引用或复用私密附件绑定。双方参与资格不足时禁用发送但保留可读历史。
