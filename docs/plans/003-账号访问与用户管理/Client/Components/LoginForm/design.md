# 登录表单组件设计

## 1. 组件职责

`LoginForm` 负责用户名和密码的输入、最小本地校验、提交事件和表单级反馈。它不调用 API、不解析错误响应、不操作路由、不读写 Cookie。

## 2. 输入与输出

组件输入至少包括：

- `onSubmit(username, password)`：由页面或认证模块适配提供；
- `loading`：是否正在提交；
- `error`：可安全展示的表单级错误。

组件输出为用户提交的用户名和密码，以及字段校验结果。组件不向外暴露密码持久化状态。

## 3. 表单字段

- 用户名：必填，使用文本输入。
- 密码：必填，使用密码输入。
- 提交按钮：请求进行时禁用并显示进行中状态。

本主题不显示注册、忘记密码、修改密码或其他附加操作。

## 4. 交互规则

1. 用户提交空用户名或空密码时，在本地显示字段错误，不发起请求。
2. 输入有效时调用 `onSubmit`。
3. 请求进行中禁止重复提交。
4. 失败后保留用户名，清空密码，显示统一错误。
5. 成功后由父页面处理导航，组件不自行跳转。
6. 组件支持 Enter 提交，并保持可访问的 label、错误关联和焦点顺序。

## 5. 样式边界

优先使用 Ant Design Form、Input、Input.Password、Button 和 Alert 等基础组件。组件自身只保留与表单布局和状态有关的样式，不引入全局主题或业务页面背景。
