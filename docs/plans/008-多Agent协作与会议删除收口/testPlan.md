# 多方交流与删除退出集成测试计划

## 1. 依据与证据

需求见[增量需求](../../需求分析/圆桌会议推广使用增量需求.md)，契约见[设计](design.md)。以下全部是待执行验收，不预填通过。单元测试验证确定性规则，真实SQLite验证约束/事务，进程测试验证崩溃恢复，浏览器和原生 MCP 宿主验证可观察流程；真实模型证据单独记录。

## 2. 场景矩阵

| 编号 | 需求/验收来源 | 输入与操作 | 预期 |
| --- | --- | --- | --- |
| E01 | FR-011/AC-011 | 人类、AgentA、AgentB自主发言，单目标/多目标/自提及/引用 | 共同消息流，@只筛选，不创建强制任务或平台业务责任 |
| E02 | FR-003/009与AC | A长期处理不回复，B和人类继续发普通及系统消息 | 服务端按权保存历史，其他会话仍可收发 |
| E03 | FR-015/017与AC | 一成员退出，其他成员继续发，创建者删除 | 退出阶段保留有权历史，删除后所有人不可再读且数据清理 |
| E04 | FR-015/017与AC | 退出者浏览/重连/接管，再明确重入 | 前三者不恢复发送，重入恢复有权历史和双方私聊；删除后不能恢复 |
| E05 | FR-001/015与AC | 暂存/已绑定文件遇删除、下载租约/文件句柄占用 | 屏障拒绝新读取、取消IO；全部文件清完才完成，失败可恢复 |
| E06 | FR-009/013/015与AC | 保存响应丢失再退出或删除；旧连接重试 | 退出可核对原发送；删除不返回正文或重发，已发外部字节不保证收回 |
| E07 | 多会议隔离 | A删除/故障，B持续聊天并补阅服务端历史 | B不阻塞且无数据、凭据或状态串线 |
| E08 | 真实与脚本证据 | 两个真实外部Agent回答不同问题；脚本注入重复、乱序和崩溃 | 分别证明自由交流和传输可靠性；模型质量不作平台保证 |

| E09 | FR-017/AC-017 | 三种组合私聊、创建者旁观、私聊@第三人、回复切页 | 正文/附件/发生情况仅双方；默认私聊范围、无强制回复 |
| E10 | FR-015/017与AC | 接管继承私聊后删除，原宿主离线后恢复并尝试历史和附件访问 | 新旧会话均不能读已删内容，迟到请求不能重建数据，用户另存文件不动 |

## 3. 数据与执行边界

使用隔离数据库和两个会议、创建者/普通成员/退出成员/非成员，以及两个独立Agent会话；包含空历史、足够跨页历史和Unicode正文。权限与并发用真实事务和可控时钟验证，不能只模拟成功DTO。附件用隔离目录，网络中断与进程重启仅对测试实例执行。

浏览器检查DOM、网络、控制台及必要截图，原生 MCP 测试记录脱敏工具名、结果与服务端关联标识。不得把账号、邀请码、令牌或完整私人正文写入测试报告。支持矩阵、模型资源和持续运行结论必须标明实际环境及样本边界。

## 4. 完成判定

所有受影响场景与前置主题回归通过，且关键异常与权限边界有真实证据，才可判定实现可验收。仅文档链接、构建或固定回复通过不能代替本矩阵。当前未执行业务测试。
