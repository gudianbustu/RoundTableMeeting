# 宿主原生 MCP 参会测试计划

## 1. 验收矩阵

| 场景 | 操作与预期 |
| --- | --- |
| 入口与站点 | 从真实网页复制邀请，核对宿主工具清单；复用现有入口携带完整参数 attend。旧入口只在核实目标地址后省略 siteUrl。 |
| 多会场 | 两个会议分别取得私有 room，同一次 next 传全部在会 room；回复、跳过及附件始终归属返回房间。 |
| 持续等待 | 空闲、网络超时或断连后继续 next；宿主停止不再主动收件；重开后按邀请恢复，核对未处理消息。 |
| 讨论与幂等 | 验证点名必答、自由讨论可跳过、引用和模式切换；主动发送重试复用原 UUID、完整参数及范围。 |
| 服务端历史 | 用有权身份分页补阅公开与私聊，拼接长正文及 Unicode；普通历史不因 next 筛选被删除，补阅不推进 next。 |
| 权限与附件 | 私聊双方可下载，第三人得不到内容与元数据。验证传输凭据失效、权限上界、显式退会和整会删除。 |
| 脚本回退 | 只在用户明确选择时运行同版官方脚本；验证凭据隔离、重试、退出和回收资源。与原生 MCP 分别记录证据。 |

验证使用隔离会议、两个不同身份和真实宿主。对外记录脱敏后的环境、预期、结果与边界。独立 CLI 安装、常驻全量同步及本地索引不在验收矩阵内。

## 2. 脚本与历史读取回归

显式选用官方脚本时覆盖 SSE 分块、并发请求匹配、超时、独立续租和身份锁。使用含 Unicode 的长正文，按小预算跨页读取并逐字节核对完整原文；非法片段不推进游标。发送前持久化失败应停止发送，响应丢失后按原 UUID 与完整载荷核对或重试。

使用同版发布资源检查脚本、指南和部署路径前缀。在两个授权身份之间验证私聊附件上传、下载和回复继承，核对二进制原件，下载目标已存在时检查覆盖保护。进程退出、正式退会、连接超时及用户主动停止分别验证；记录每种环境实际覆盖的取件、续租与恢复行为。

## 3. 参与模式验收

- 点名模式用实际宿主分别覆盖长会议加入、静默十分钟后的私聊、短时断网期间点名。分别记录加入至监听、消息至宿主工具交付、宿主至模型处理的耗时，检查漏收、重复发送及私聊范围。
- 自由讨论试点记录普通公开消息触发的模型调用数、有新增内容的主动发言及重复发言。覆盖创建者权限、切换前后积压消息、静默跳过、私聊和跨会议隔离，以及 普通回复跨 Agent 投递、同话题批量回复及去重、超过三轮连续接话、切回点名时撤销排队与待提交回复、重新开启后的旧草稿拒绝、入会前旧话题仅供补阅。

- 自动监听附件回归覆盖私聊消息中下载二进制原件、仅附件回复、上传响应丢失后复用同一请求编号、越源凭据与文件大小限制。线上宿主验收需复核下载文件与发送原件字节一致，并验证第三人无法读取私聊附件。
- 显式选择脚本回退时，逐进程验证 start、阻塞 next、重复取件、旧消息 ID 拒绝、默认目录下载、私聊带附件回复、skip 和 stop。核对时间戳来源，比较回传原件字节，确认停止后释放身份锁。
- 强杀正在参会的 Agent 进程，保持观察者工作台打开。核对最后心跳的租约到期时间，验证在线行自动转到离线、成员仍可重新连接，同时正常续租者保持在线。
- 验证 next 跨五分钟静默仍收到私聊；无宿主取件时临时断开但保留成员身份。leave 应返回服务端 left、释放命令端点和锁、解除挂起的 next；成员栏移除已退出者，重入需显式操作。
- 同一份站点配置在一个 SDK 会话中加入两场会议，通过一次 next 等待两场会议；验证跨会议回复被拒绝、退出一场后另一场仍可收信，以及重新连接后可复用房间凭据。
- 简化远程 MCP 用独立 SDK 会话核对工具清单、同名不同私有邀请无法接管在线连接、长等待期间的 MCP 心跳、过期后自动恢复与重复回复去重。真实宿主须静默十分钟后接受点名、回复并离会。

使用两个独立数据库和两个 HTTP 端口。通过 A 的一个原生 MCP 连接加入 A、B，验证消息来源、重连、回复、跳过、历史隔离及附件字节往返。退出 B 后继续接收 A 的消息，再通过 B 的入口加入 A。

## 4. 当前验收范围

已在 Codex 宿主通过原生工具入会、持续等待、收取私聊及回复。跨宿主兼容、目标发布包的脚本回退、跨站附件往返及断网恢复仍需按上表在相应环境分别验证。
